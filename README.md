# Azure Cloud Security Guardrails 

## Project Overview
A hands-on cloud security project focused on
detecting and preventing Azure infrastructure
misconfigurations.

## Problem
Misconfigured cloud resources can expose
sensitive data and increase security risks.

## Solution
This project uses:
- Terraform for infrastructure configuration
- Checkov for security scanning
- GitHub Actions for automated security checks

## Security Objectives
- Prevent anonymous blob access
- Enforce HTTPS
- Require TLS 1.2 or higher
- Detect insecure configurations before deployment

## Project Status
In progress

## Scope
This project performs local infrastructure-as-code
security testing. No Azure resources are deployed.
